## Overview
This repository contains a comprehensive chemoinformatics database mapping the secondary metabolites of 25,634 plant species indigenous to Indonesia. The database features 34,105 unique natural compounds curated computationally through duplicate elimination, molecular weight filtering, and Pan Assay Interference Compounds (PAINS) removal.

## Key Features
* **Advanced ADMET Profiling:** In-depth pharmacokinetic and toxicity predictions, including hERG (cardiotoxicity), DILI (hepatotoxicity), Ames (mutagenicity), and CYP450 enzyme inhibition probabilities.
* **Optimized 3D Structures:** Ready-to-use 3D coordinates for large-scale Structure-Based Virtual Screening (SBVS) and Computer-Aided Drug Design (CADD).
  * `admet_0.7.rar`: Contains 14,115 "Safe" optimized 3D structures (threshold < 0.7).
  * `admet_0.5.rar`: Contains 7,785 "Ultra-safe" optimized 3D structures (threshold < 0.5).
* **Comprehensive Metadata:** The `3D Database of Secondary Metabolites of Indonesian Biodiversity.xlsx` provides complete SMILES and analytical data.
